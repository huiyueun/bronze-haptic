청동의 울림

손끝으로 듣는 청동방울 · 다감각 디지털 아트 도슨트

작품 소개

「청동의 울림」은 국보 「전 덕산 청동방울 일괄」의 네 가지 방울, 팔주령·쌍두령·조합식쌍두령·간두령을 휴대폰으로 만나는 다감각 디지털 도슨트입니다.

이 방울들은 청동기 시대 의례에 쓰였을 것으로 보는 유물로, 충청남도 덕산에서 나왔다고 전해집니다.

유리장 너머에서 ‘만지지 마세요’였던 청동방울을 손끝과 귀, 진동으로 감상하도록 만들었습니다.

국가유산청이 공개한 실제 유물의 3D 자료를 화면 가운데에 크게 보여 주고, 휴대폰을 흔들면 방울 소리와 진동, 화면 아래 물결무늬가 같은 리듬으로 울립니다.

유물 살펴보기에서는 손끝으로 유물의 윤곽을 따라가며 부위마다 짧은 해설을 듣습니다.

시각장애인과 비시각장애인이 같은 유물을 화면, 소리, 진동으로 함께 감상하는 것을 목표로 했으며, 안드로이드 톡백으로도 쓸 수 있습니다.

사용법

  1. 안내 방식 고르기. 첫 창에서 스크린리더 톡백 사용 중, 또는 앱 기본 음성 사용을 고릅니다. 앱 기본 음성에서는 단추를 한 번 누르면 이름을 읽어 주고, 한 번 더 누르면 실행됩니다. 소리와 동작 센서를 허용해 주세요.
  2. 유물 고르기. 화면 아래쪽의 팔주령, 쌍두령, 조합식쌍두령, 간두령 가운데 하나를 누릅니다.
  3. 돌려 보기. 가운데 유물을 손가락으로 좌우로 밀면 유물이 돌아갑니다. 키보드에서는 좌우 화살표를 씁니다.
  4. 흔들어 듣기. 휴대폰을 가볍게 흔들면 방울 소리가 나고, 화면 아래 물결무늬와 진동이 같은 리듬으로 반응합니다. 세게 흔들수록 크게 울리고, 휴대폰을 기울이면 울림이 조금 달라집니다.
  5. 유물 살펴보기. 맨 아래 유물 살펴보기를 누르면 유물이 멈춥니다. 손끝으로 화면을 더듬어 유물 안에 들어가면 진동이 오고, 번호 지점에 가까워질수록 안내음이 빨라지고 높아집니다. 지점에 처음 닿으면 부위 이름을, 손을 뗐다가 같은 지점을 다시 누르면 짧은 해설을 들려줍니다. 유물마다 설명 지점이 세 곳 있습니다. 다 보았으면 돌아가기를 누릅니다.
  6. 톡백으로 쓰기. 한 번 터치하면 읽고, 두 번 탭하면 실행하며, 오른쪽으로 쓸면 다음 항목으로 갑니다. 유물 살펴보기에서는 번호가 붙은 부위 단추를 두 번 탭하면 해설을 읽어 줍니다.
  7. 알아 두기. 진동은 지원되는 안드로이드 브라우저에서만 납니다. 아이폰에서는 방울 소리와 화면 무늬로 체험합니다. 이 안내는 오른쪽 위 사용법 단추로 언제든 다시 열 수 있습니다.
